# Trade World

A responsive dark-mode paper trading platform built with React, Vite, Redux Toolkit, Tailwind CSS, and React Router.

## Features

- Demo trading wallet seeded with ₹10,00,000.
- Simulated Indian-market price movement.
- Market and limit orders with order history and cancellation.
- Watchlist, portfolio holdings, P&L, allocation, and account reset.
- Page titles update automatically with navigation.

## Run

```bash
npm install
npm run dev
```
